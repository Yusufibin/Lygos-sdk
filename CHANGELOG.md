# Changelog

## 0.2.0

- Configurable connect/read timeouts, reusable HTTP session and context manager.
- Typed HTTP errors, rate-limit exception, JSON shape validation and API-key redaction.
- Integer amount validation, encoded order IDs and disabled automatic redirects.
- No implicit request retry; errors preserve an indeterminate payment outcome.
- Modern packaging, MIT license file, generated-file cleanup and offline CI.
- Requires Python 3.10+; existing method names and imports retained.
